# 2026-07-12 RTK Token Killer 環境變數控制機制

## 問題描述

RTK（Rust Token Killer）在開發過程中可能會阻礙 AI 模型開發，特別是：
- 調試早期需要看完整輸出
- 性能分析需要精確的 stack trace
- 時序敏感或間歇性故障無法用壓縮輸出診斷

## 解決方案

### 1. 環境變數開關

在 `AGENTS.md` 中添加 **RTK 使用政策** 章節，說明：
- `COPILOT_RTK_ENABLED=true` — 啟用 RTK（預設）
- `COPILOT_RTK_ENABLED=false` — 關閉 RTK（保留完整輸出）

### 2. 快速切換腳本

新增兩個平台特定的切換腳本：

| 平台 | 路徑 | 指令 |
|------|------|------|
| macOS / Linux | `.agents/skills/rtk-token-killer/rtk-toggle.sh` | `bash rtk-toggle.sh {enable\|disable\|status}` |
| Windows | `.agents/skills/rtk-token-killer/rtk-toggle.ps1` | `.\rtk-toggle.ps1 -Action {enable\|disable\|status}` |

### 3. 文件更新

- **AGENTS.md**: 新增「RTK Token Killer 使用政策」章節
- **SKILL.md**: 新增「Enable / Disable RTK」與「When to Disable RTK」章節

## 使用場景

### ✅ 啟用 RTK（預設）
```bash
export COPILOT_RTK_ENABLED=true
# 或執行腳本
bash .agents/skills/rtk-token-killer/rtk-toggle.sh enable
```
適用於：
- 日常開發（git、npm、python 等）
- 大型 log 輸出（測試、build、docker logs）
- 快速迭代原型

### ❌ 關閉 RTK
```bash
export COPILOT_RTK_ENABLED=false
# 或執行腳本
bash .agents/skills/rtk-token-killer/rtk-toggle.sh disable
```
適用於：
- 調試早期，需要完整 log 理解根源
- 性能分析，需要精確的細節
- 時序敏感或間歇性故障排查

## 實作細節

### rtk-toggle.sh (macOS / Linux)
- 自動找到合適的 shell 配置文件（.zshrc、.bash_profile 等）
- 新增或修改 `COPILOT_RTK_ENABLED` 環境變數
- 支持 enable / disable / status 三個操作

### rtk-toggle.ps1 (Windows)
- 寫入 PowerShell Profile
- 支持 enable / disable / status 三個操作
- 提示用戶執行 `. $PROFILE` 重新載入配置

## 開發指南

### 工作流建議

1. **日常開發** → 保持 RTK 啟用（預設）
2. **遇到問題** → 立即關閉 RTK 重新執行
   ```bash
   export COPILOT_RTK_ENABLED=false
   # 重新執行命令或 run_in_terminal
   ```
3. **問題解決** → 重新啟用 RTK 節省 token
   ```bash
   export COPILOT_RTK_ENABLED=true
   ```

### 驗證方式

- 手動設置環境變數：`echo $COPILOT_RTK_ENABLED` 或 `echo %COPILOT_RTK_ENABLED%`
- 使用腳本查看狀態：`bash rtk-toggle.sh status`
- 查看 RTK 節省統計：`rtk gain`
